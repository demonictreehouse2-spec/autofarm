# AutoFarm Addon (Meteor Client 26.3)

AutoFarm extracted from [Meteor Rejects](https://github.com/AntiCope/meteor-rejects) (GPL-3.0)
as a standalone Meteor addon. It adds an "AutoFarm" tab to Meteor's click GUI.

## Build
Requires JDK 25 and internet access (first build only).

    ./gradlew build          # Windows: gradlew.bat build

Jar: `build/libs/autofarm-addon-1.0.0.jar`

## Install
Put the jar in `.minecraft/mods` together with Meteor Client 26.3 (built against 26.3-22)
and Fabric Loader >= 0.19.5.
